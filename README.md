# Training_Programs

مستودع لتحويل برامج ومراجع التكوين إلى صيغ نصية قابلة للقراءة البشرية والآلية، مع الحفاظ على المصدر وتوثيق أي تطبيع أو تعارض داخلي دون تصحيح صامت.

## مبدأ التحويل

لكل وثيقة يمكن أن توجد ثلاث طبقات متكاملة:

- **Markdown دلالي** للقراءة والمراجعة البشرية، باستعمال العناوين والقوائم والجداول عندما يمكن تمثيل البنية دون تخمين.
- **Raw transcription** للاحتفاظ بالنقل النصي المحافظ والمحاذاة المستخرجة من PDF كطبقة تدقيق.
- **JSON** للمعالجة البرمجية والفهرسة والتحليل.

كما يستخدم المستودع:

- `manifest.json` لتتبع المصدر والبصمات الرقمية.
- `*.normalized.json` للبيانات المنظمة عبر الوثائق.
- `DISCREPANCIES.md` لتوثيق التناقضات والاختلافات وقواعد التعامل معها.

## قاعدة أساسية

لا تُصحح أخطاء أو تناقضات المصدر بصمت. إذا كان تحويل جدول أو خلية يحتاج إلى تفسير غير مؤكد، تبقى طبقة النقل الخام متاحة ويُتجنب تقديم الاستنتاج على أنه نص المصدر.
